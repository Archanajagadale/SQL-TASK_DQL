#SQL-TASK-DQL
WHERE, LIKE, GROUP BY, HAVING, LIMIT and OFFSET

Used WHERE to filter records based on specific conditions.

Used LIKE to search for patterns in text data.

Used GROUP BY to group records based on common column values.

Used HAVING to filter grouped data based on aggregate conditions.

Used LIMIT to restrict the number of rows returned.

Used OFFSET to skip a specified number of rows.
